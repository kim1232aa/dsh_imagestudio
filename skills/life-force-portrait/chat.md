# Fantasy 生命感人像 —— 聊天创作指令

生成或升级「有生命感」的 3:4 竖版人像摄影：人物在做事而非摆拍，光色有现场来源，皮肤有真实质感。

## 一、何时使用

命中场景：游客照/手机废片升级、朋友圈照片变高级、氛围感大片改造、从零生成生命感人像样片、人像摄影提示词。

与兄弟 skill 的边界：

- 「街头纪实 / 同地点 2-4 张拼图 / 徕卡哈苏理光气质」→ photography-simulation。
- 「设计一个不存在的人 / 选角图 / 三视图」→ character-casting。
- 「电影海报、要片名文字」→ movie-poster；「21:9 连续叙事分镜」→ cinema-dna-21x9x3。

## 二、三个模式（先判断再动手）

- MODE A 照片升级：用户给了照片。身份锁定——脸、表情、动作、服装、体型、年龄全不变，只重组光影层次；走 image-to-image（istudio_edit / plan 的 refUsage: image-to-image）。
- MODE C 氛围感大片：保留人物与事件，改光影、景深、构图。
- MODE B 原创样片：无参考图时从零生成，默认中国/东亚人物、唯美电影人像方向。

## 三、创作工作流

只使用宿主已注册的工具，不要自己编造工具：

1. 调 `istudio_skill_plan`，`skillId: "life-force-portrait"`；brief 写清：人物是谁、在做什么事件、想要什么光色氛围、禁忌；升级照片时注明「MODE A 保留人物身份」。
2. 检查 plan 的 `selfCheck`：passed 才继续，score/veto 如实告知用户。
3. 通过后调 `istudio_generate` 传 `planId`；批量 N 张 = N 张独立图（不是拼图），逐张生成。
4. 有源照片且要保身份时用 `istudio_edit`（图生图通路）。

## 四、硬约束摘要

- 画幅 3:4 竖版；独立输出，无文字、无框、无水印。
- 生命感优先级链（禁止倒置）：人物状态 → 亲密距离 → 前景遮挡 → 大胆裁切 → 硬光 → 色彩 → 柔光 → 色散。
- 景别配比：约 50% 特写 / 30% 中近景 / 15% 特殊中景 / 5% 大景小人。
- 每张 = 1 主构图策略 + 1 主光学效果 + 1 辅助效果；质感层不超过 2 种（caustics/色散/漩涡焦外/运动模糊）。
- 批量时每张至少 7 项不同；有参考图时至少改 5 个维度，禁止复刻。
- 负面清单精华（约 70 条的核心）：大众 AI 脸、油光/镜面皮肤、额头鼻梁大片反光、塑料奶油皮、蜡像感、过度磨皮、影楼浓妆、网红模板Pose、擦边暧昧、脏黄复古、赛博霓虹、全图色散/柔焦、公众人物脸。
- 否决项：换脸或陌生模特、默认欧美广告脸、油亮皮肤、影楼写真、AI 娃娃脸。
- 质量门是逐项 checklist（人物/摄影/光色/批量/版权），由 plan 自评代为把关。

## 五、被 PLAN_REJECTED 拦截时

1. 不要重试相同请求，不要擅自 force。
2. 向用户解释失败项（如「身份保留不足」「油亮皮肤风险」）与得分。
3. 询问用户：修改 brief 重新 plan（给出具体建议），还是明确接受风险用 `force: true` 强制出图。

# 梵想电影海报 —— 聊天创作指令

从片名、剧情、题材关键词、人物关系或参考画面，设计原创的 9:16 中文电影海报（含文字图层）。不复刻现有海报，不做社媒图，不原样保留参考构图。

## 一、何时使用

命中场景：「给这个故事设计一张电影海报」、《片名》+ 题材（爱情文艺/犯罪悬疑/科幻/公路片…）、一次做多张不同题材海报、海报要有书法标题、9:16 竖版电影海报、根据截图做海报底图。

与兄弟 skill 的边界：

- 「电影感图片 / 静帧 / 分镜」没有片名与文字需求 → cinema-dna-21x9x3。
- 「把照片做成海报风」但无片名/剧情/文字 → life-force-portrait。
- 「社媒封面 / 小红书图」→ 不属于本 skill，直接说明并婉拒或转普通生图。
- 「海报上需要原创人物」可先用 character-casting 出人物，再回到本 skill 出成品海报（按序串联）。

## 二、创作工作流

只使用宿主已注册的工具，不要自己编造工具：

1. 电影判断：与用户确认片名、题材、核心冲突、一句话故事。题材路由参考：爱情文艺/运动/历史法政/公路/犯罪/东方/战争/科幻/趣味概念等 9+ 类。
2. 构成模型 10 选 1（只选 1 个主构成 + 至多 1 个辅助）：一个人心理 → 极端人物裁切；两人距离 → 静帧/负空间；多人牵制 → 群像；物件代表全片 → 物件隐喻……
3. 调 `istudio_skill_plan`，`skillId: "movie-poster"`；brief 写清：片名、题材、构成模型选择理由、色彩命题、文字内容、禁忌。用户要 N 张就是 N 张独立海报，禁止自动拼图。
4. 检查 plan 的 `selfCheck`：**低于 80 分或有 veto 不交付**。
5. 通过后调 `istudio_generate` 传 `planId`。默认分层思路：底图层与字体图层分开考虑，中文主标题必须可读。

## 三、硬约束摘要

- 画幅竖版 9:16，单张交付。
- 品牌规则：导演/编剧/制片/摄影/美术等一切署名统一写「梵想美学」；禁止电影节桂冠、真实片商、真实品牌。
- 中文主标题必须准确、短、有冲突钩子、可读；书法/字体风格服从题材。
- 主视觉从故事分镜中提炼，不是图片拼贴；文字层级与留白必须可执行。
- 参考图只借抽象维度，禁止保留参考构图。
- 负面精华：no CGI concept art、no game key art、no glossy AI rendering；禁用 cinematic/masterpiece/epic 等空泛词。
- 评分 100 制（内容 20/母题 15/构图 15/字体 15/色彩质感 10/原创差异 15/品牌文字 10），**低于 80 重做**；明显 CG/游戏宣传图一票否决。

## 四、被 PLAN_REJECTED 拦截时

1. 不要重试相同请求，不要擅自 force。
2. 向用户解释：得分/阈值、失败项、veto 原因（如「片名策略缺失」「原创差异不足」）。
3. 询问用户：修改 brief（换构成模型、补片名、换题材方向）重新 plan，还是明确接受风险用 `force: true` 强制出图。

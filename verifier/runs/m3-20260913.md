## 范围

- 页签重构为 10 个（冻结清单）：生图 gen | 视频 video | 动图 gif | 反推 reverse | 无限画布 canvas | UI设计 uidesign | 我的素材 assets | 电商 ecom | 模板库 tpl | 设置 settings；gallery 页签删除，能力由 assets 页 generated 筛选承接，旧 localStorage 画廊给一次性迁移提示（可清除/保留）。
- gen 页：模式 chip 精简为 文生图/图生图；接 422 语义（分数框 + 仍然出图）。
- 新页签：video（渠道下拉按 kinds 过滤、文生/参考图、比例/时长、提交→轮询 /api/jobs→播放+下载+抽帧）、gif（两步流：/api/gif 出帧 → 帧条启停 + 延时 50-500ms + 循环次数 → /api/gif/recode 合成下载）、reverse（上传/粘贴→视觉渠道→模板 简洁/详细/分镜→/api/describe→复制/回填 gen）、assets（服务端网格 + 搜索/筛选/分页/多选/重命名/删除/打包/上传）。
- 新端点：
  - GET /imagestudio/api/assets 扩展 `?q= ?type=generated|uploaded|all offset/limit`（响应加 total/offset/limit，条目加 kind/size/mtime）
  - POST /imagestudio/api/assets/upload（multipart 或 base64 JSON，≤10MB → .dsh/image-studio/uploads/）
  - POST /imagestudio/api/assets/rename {path,name}
  - POST /imagestudio/api/assets/delete {paths[]}
  - GET /imagestudio/api/assets/zip?paths=a,b,c（compose/zip.ts，Content-Disposition 附件）
  - POST /imagestudio/api/gif/recode {frames[], delayMs, loop}（encodeGif 本地合成，新增可选 loop 参数，默认 0=无限保持旧行为）
  - /api/gif 响应加 frameList；/api/describe 支持 providerId
  - 全部文件读写/删除/打包过 assertInsideWorkspace（写操作限定在 .dsh/image-studio 内）
- 422 契约（SPEC §3 逐字）：带 planId 且 plan.selfCheck.passed===false 且无 force:true → HTTP 422，body = `{"error":{"code":"PLAN_REJECTED","score":number,"threshold":number,"failures":string[],"veto":string|null}}`。threshold 取 plan.skillId 对应 preset.scoring.threshold。force:true 时 UI 路由层把 force 写进 request 对象（`as any` + TODO-merge 注释），M1 pipeline 闸门合并后自然生效；同时 catch 兜底把 pipeline 抛出的 PLAN_REJECTED 映射回同一 422 结构。
- UI 交互：api() 透传 httpStatus；检测到 error.code==='PLAN_REJECTED' 时分数框展示 score/threshold/failures/veto + 「仍然出图」按钮（重发同一请求加 force:true）。

## 偏差 / 说明

- SPEC 写 `$HOME/dsh_imagestudio`，本机实际主仓在 `/mnt/agents/output/work/dsh_imagestudio`；worktree 建于 `/mnt/agents/output/work-feat-workbench-tabs`。/mnt 文件系统不支持 symlink，node_modules 经 /tmp 安装后 `cp -rL` 拷入。
- pipeline（packages/core）当前尚无 force/PLAN_REJECTED 闸门（M1 并行开发中），按任务约定在 UI 路由层实现 422 并把 force 透传进 request 对象；M1 合并后语义一致（force=true 双门均放行，无 force 由 UI 门先行 422）。
- /api/assets/upload 除 multipart 外也接受 base64 JSON（与既有 /api/upload 同构），属超集；MemoryWebServer.fetch 不支持自定义请求头，测试走 base64 通路，multipart 经 preview curl 实测。
- GIF 重编码走本地 encodeGif（不依赖 ffmpeg），延时钳制 50–500ms、循环 0–65535（0=无限）。
- 未触碰 packages/core、packages/skills、plugin.ts、packages/client。

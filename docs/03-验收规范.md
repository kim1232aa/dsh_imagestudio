# DSH Image Studio 插件 · 验收规范

> 版本：v0.2.1（并存 `@dickpy/dsh-imagegen`）  
> 原则：能自动断言的自动化；「好不好看」才人工。  
> P = 发布必须过；S = 可带已知问题。

---

## 0. 验收环境

- 官方 `dsh web` / Desktop，或 `dsh --profile web --patch ./examples/dsh-web.patch.yml`
- 本机允许已安装 `@dickpy/dsh-imagegen`（id `imagegen`）。**不得抢它的侧栏「生图」和 `generate_image`。**
- mock provider 必须能离线出图
- 禁止用自绘非 DSH 预览代替本表标「官方壳」的 UI 项；HTTP/工具项可用 MemoryWebServer 自动化

---

## 1. 独立页面与入口（AC-UI）P

| ID | 断言 |
|---|---|
| AC-UI-01 | 侧栏出现本插件入口文案 **技能台**（有 dsh-imagegen 时不替换其「生图」双 Tab） |
| AC-UI-02 | 点「技能台」打开本窗口 `/imagestudio`，不是外站 |
| AC-UI-03 | 工作台顶栏有「回对话」链到 `/` |
| AC-UI-04 | `GET /imagestudio` 返回含 `Image Studio` 的 HTML，状态 200 |
| AC-UI-05 | 工作台五个 skill id 与 preset 一致 |
| AC-UI-06 | 文生图 mock 至少 1 张 |
| AC-UI-07 | 选 cinema-dna 后界面**默认** 21:9；用户改比例仍可出图（红线：不锁死） |
| AC-UI-08 | 策划在 veto / 低分时展示 failures；「就这样出图」仍可点，provider 仍可被调用 |
| AC-UI-09 | 三联走 compose，不把「画三格」送进 generate |
| AC-UI-10 | 产物写入 `.dsh/image-studio/<session>/<task>/`；工作台与 `istudio_assets` 同一索引 |
| AC-UI-11 | 卸载 image-ui 后 `/imagestudio` 不再由本插件提供；入口脚本不再注入 |
| AC-UI-12 | `dump-config` 出现 `image-studio` **不能**代替 AC-UI-01（有配置 ≠ 有入口） |
| AC-UI-13 | 不注册 `generate_image` / `edit_image` / `get_image_generation_task` / `cancel_image_generation_task` |
| AC-UI-14 | 不注册 `/favicon.ico`、不挂 `/api/dsh-imagegen` |

S 项：

| ID | 断言 |
|---|---|
| AC-UI-S1 | 工作台「设置」页可填渠道（密钥只写 env 名） |
| AC-UI-S2 | 灵感区可一键把案例写进简报 |

无限画布 / 电商 / 视频：有 mock 通路，不作为本期 P 签字项。

## 2. 插件生命周期（AC-LC）P

| ID | 断言 |
|---|---|
| AC-LC-01 | `--patch` 或 profile bundle 后 dump-config 含 `id: image-studio` |
| AC-LC-02 | boot 后 `image-*` 纤维为 ACTIVE，不是 Failed |
| AC-LC-03 | 无 `webServer` 时 ui 不得把 core/tools 卡在 PENDING |
| AC-LC-04 | 卸载 image-tools 后 6 个 `image_*` 名从 `ctx.tools` 消失 |
| AC-LC-05 | 与 `id: imagegen`（dsh-imagegen）可同时出现在 dump-config |

---

## 3. 工具契约（AC-TL）P

6 个工具名：`istudio_skill_plan` `istudio_generate` `istudio_edit` `istudio_describe` `istudio_compose` `istudio_assets`。

| ID | 断言 |
|---|---|
| AC-TL-20 | 工作台对同一 skillId+brief 的 aspectRatio / veto 与 `istudio_skill_plan` 一致 |
| AC-TL-21 | 工作台生成的文件能被 `istudio_assets` 列到 |

其余 AC-TL-01…19 沿用（参数校验、n=1–4、compose 需 3 张、describe 不写 system prompt）。

---

## 4. 事件（AC-EV）P

| ID | 断言 |
|---|---|
| AC-EV-01 | before-request 观察者忘 next() 会卡住，测试里有反例 |
| AC-EV-02 | guard bail 后 provider.generate 不被调用 |
| AC-EV-03 | 工作台出图也会触发 after-result |

---

## 5. Skill 引擎（AC-SK）P

加载、21:9 默认、bannedPromptTerms、threshold 82 展示、海报显式触发、CharacterSheet 注入保留。分数不拦出图。

| ID | 断言 |
|---|---|
| AC-SK-20 | UI 选择器列出的 id 集合等于 `imageSkills.list()` |
| AC-SK-21 | UI 在 veto 时展示的 failures 与 plan.selfCheck.failures 相同 |

---

## 6. 任务与产物（AC-AS）P

| ID | 断言 |
|---|---|
| AC-AS-01 | 任务目录在 `.dsh/image-studio/<session>/<task>/` |
| AC-AS-02 | 取消或超时不留下半写入密钥 |
| AC-AS-03 | 工作台与工具写入同一索引 |
| AC-AS-04 | 路径穿越（`../`）被拒绝 |
| AC-AS-05 | 队列走 JobStore / jobs，而不是无界 Promise.all |

---

## 7. 安全（AC-SEC）P

密钥不进 plan.json；analysis-only 参考图不进 i2i；`/imagestudio/api/file` 不得读出工作区外文件。

---

## 8. 人工质量（AC-HQ）S

沿用三联 / 人像 / 海报抽样。抽检在工作台完成。mock 色块不算摄影质量。

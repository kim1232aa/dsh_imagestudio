# 03 · 验收标准

**先读 `00-参考来源与项目定位.md`。**

## 这份文档的规矩

**每一条都必须是可判定的。** 不接受"基本能用"、"大致正常"、"体验良好"这种结论。每条要么给出**具体数值**，要么给出**具体操作步骤 + 预期结果**。

**给 AI 的执行要求：**

1. 每做完一个功能，回来把该功能的全部条目走一遍
2. 勾不上的，**要么继续做，要么明确写出做不了的原因** —— 不许跳过去做新功能
3. **不许写假实现**：按钮存在但点了没反应、返回写死的假数据、异常被吞掉只打印日志，都算不通过
4. 标 **🔴 红线** 的条目，任何一条不通过就必须立刻停下来改，不能带着往下走

**核心功能（图片、视频、画布）的标准比其他功能严。** 那三块是这个工作台的立身之本，宁可其他功能晚做，也不许核心功能半残。

---

## 零、红线（先过这一关）

任何一条不通过，其余验收全部作废。

- 🔴 不选任何 skill，输一句提示词能直接出图
- 🔴 skill 评分再低，「出图」按钮仍可点击（DOM 上没有 disabled）
- 🔴 评分低时不弹窗、不要求二次确认、不自动重试
- 🔴 全程不存在"这个我不能生成"类的拒绝
- 🔴 没有敏感词过滤、没有关键词黑名单、没有内容审查
- 🔴 自动带上的负面词在界面上看得见，且能删掉
- 🔴 skill 指定的比例显示在界面上，用户手动改能改动
- 🔴 不自动删除任何已生成的图片或视频
- 🔴 不自动改写用户输入的提示词（用户主动点「增强」除外）
- 🔴 密钥在浏览器开发者工具、日志、报错信息里均不可见

## 三、核心功能 1：普通生图

### 3.1 出图正确性（硬指标）

- [ ] 9 档比例逐个生成，**用图片属性核对实际像素比**，误差 ≤1%
  - 逐档记录：1:1 / 3:4 / 4:3 / 9:16 / 16:9 / 2:3 / 3:2 / 21:9 / 自动
- [ ] 4 档清晰度逐个生成，**实际像素尺寸有明确区别**，记录各档实测尺寸
- [ ] 张数选 1/2/3/4，**实际出图数量分毫不差**
- [ ] 同一提示词 + 同一 seed + 同一模型，两次出图结果一致（渠道支持 seed 时）

### 3.2 图生图

- [ ] 本地上传参考图成功
- [ ] 拖拽图片到上传区成功
- [ ] 粘贴剪贴板截图成功
- [ ] 从历史记录一键转参考图
- [ ] 从画廊一键转参考图
- [ ] 从结果卡一键转参考图
- [ ] 参考图 + 修改指令，**出图与原图有明显承接关系**，不是完全无关的另一张
- [ ] 超过大小限制的图片被拒绝，并明确提示上限是多少

### 3.3 任务与中断

- [ ] 生成中显示进度和已用秒数，秒数实时跳动
- [ ] 点取消后，**上游请求真的中止**（网络面板确认请求已 abort）
- [ ] 取消后半成品文件被清理，不留空目录
- [ ] 失败能一键重试，参数无需重填
- [ ] 生成过程中切换标签页，任务不中断
- [ ] 生成过程中页面其他区域可正常操作
- [ ] 关闭页面再打开，未完成任务仍在
- [ ] 进程异常退出重启后，**不存在永远卡在"处理中"的幽灵任务**

### 3.4 结果与历史

- [ ] 多图并排显示
- [ ] 全屏预览：滚轮缩放范围至少 0.5x–3x
- [ ] 全屏预览：← → 键翻页
- [ ] 复制提示词、下载、加画廊、加对话、转参考图、重新生成 —— 六个动作全部可用
- [ ] 每次生成自动进历史，含缩略图、提示词、模型、模式、参数
- [ ] 点历史条目，**全部参数准确回填**（提示词、模型、比例、清晰度、张数逐项核对）
- [ ] 按关键词搜索命中
- [ ] 按模型筛选正确
- [ ] 按比例筛选正确
- [ ] 删单条、清空均生效
- [ ] 关页面重开，历史完整保留

### 3.5 辅助

- [ ] 空状态显示灵感案例，点击回填提示词
- [ ] 「随机」换一批，内容确实变化
- [ ] 提示词增强：输入"画只猫"，输出是结构完整的长提示词
- [ ] 未配置增强模型时明确引导，不静默无反应
- [ ] 右侧对话面板可展开收起

## 四、核心功能 2：视频生成

**标准与图片同级。视频不是附属功能。**

### 4.1 架构（硬性）

- [ ] 🔴 **没有插件套插件**：视频协议内置在代码里，用户只需在设置里填地址密钥，不需要 clone 插件包、放目录、重启
- [ ] 视频任务和图片任务走**同一套队列**
- [ ] 视频和图片进**同一个历史记录**
- [ ] 视频和图片进**同一个画廊**
- [ ] 视频渠道配置方式和图片渠道一致，不是另一套界面

### 4.2 生成

- [ ] 文生视频：输提示词能出视频
- [ ] 图生视频：传首帧图能出视频
- [ ] 尾帧图上传可用（渠道支持时）
- [ ] 参考视频、参考音频上传可用（渠道支持时）
- [ ] 时长可选，**实际视频时长与所选一致**（用播放器核对）
- [ ] 分辨率档位可选，**实际分辨率与所选一致**
- [ ] 比例可选，实际比例正确
- [ ] 模型可选，切换生效

### 4.3 异步与长等待（视频的关键难点）

- [ ] 提交后立刻返回任务，**界面不卡死**
- [ ] 轮询过程中进度可见，**不是一个转圈转三分钟不给任何信息**
- [ ] 显示已等待时长
- [ ] 等待超过 1 分钟时仍有明确状态反馈
- [ ] 能中途取消，取消后轮询真的停止（网络面板确认不再有轮询请求）
- [ ] 上游失败时，**原始失败原因透传给用户**，不是笼统的"生成失败"
- [ ] 🔴 上游返回的视频 URL **原样使用，不做任何域名改写**

### 4.4 结果

- [ ] 视频能在页面内直接播放
- [ ] 播放器有进度条，可拖动
- [ ] 显示时长、分辨率、所用模型
- [ ] 能下载
- [ ] 能加入画廊
- [ ] **能抽取任意一帧当作图片使用**
- [ ] 抽取的帧能拿去当图生图的参考图
- [ ] 抽取的帧能加入画布
- [ ] 能重新生成
- [ ] 档位价格差异在界面上标注清楚（标准/高清/超清）

### 4.5 与其他功能打通

- [ ] 生图结果卡上有「拿去做视频」，点了自动带入当首帧
- [ ] 画廊里的图有「拿去做视频」
- [ ] 画布上的图片节点能连到视频生成节点
- [ ] 视频生成的结果能回到画布成为节点

## 六、创作 Skill

### 6.1 基本流程

- [ ] 六个入口名称清晰可辨：电影三联 / 三联封面 / 电影海报 / 人像 / 摄影 / 角色
- [ ] 本地未装 skill 时，入口提示如何安装，不是空白
- [ ] 装了 skill 后能识别到
- [ ] 输入一句话，点「想方案」能出方案
- [ ] 🔴 **方案的判断部分是人话**——找一个不了解这个项目的人读，能读懂在说什么
- [ ] 方案含每张图的提示词、比例、负面词
- [ ] 方案每一部分都可编辑
- [ ] 改完能出图
- [ ] 方案可保存、可调取复用
- [ ] 出图失败后方案仍在

### 6.2 电影三联（硬指标）

- [ ] 出 **3 张**，每张实测比例 **21:9**，误差 ≤1%
- [ ] 本地拼接成一张纵向长图
- [ ] 🔴 **相邻两张间黑色间隔在 8–12 像素之间**（放大数像素）
- [ ] 🔴 拼接图上**无文字、无序号、无水印、无边框、无圆角、无阴影**
- [ ] 三张图之间确有变化，不是同机位换角度
- [ ] 三张单图 + 拼接图，共 4 个文件全部保存

### 6.3 三联封面 / 电影海报

- [ ] 三联封面：实测 3:4
- [ ] 电影海报：实测 9:16
- [ ] 两者是**两个分开的入口**，名称不混淆
- [ ] 海报分层产出：底图层、字体层、合成图、合成记录，**四件齐全**
- [ ] 字体层由图像模型生成，**代码中无本地字体渲染调用**
- [ ] 有「只重出字体层」按钮
- [ ] 点了之后**底图文件哈希不变**
- [ ] 合成记录能看懂，照着能复现合成结果
- [ ] 署名默认值正确，且可修改

### 6.4 人像 / 角色

- [ ] 人像两个子模式可区分
- [ ] 升级模式：出图仍是原来那个人，不是换脸
- [ ] 🔴 **角色 skill 默认只出一张，不自动出三视图**
- [ ] 勾选三视图后才出多角度
- [ ] 三视图中各角度为同一人
- [ ] 批量出多个角色时，彼此长相有明显区别

### 6.5 跨 skill

- [ ] 角色 skill 产出的人物能在三联中引用
- [ ] 引用后三张图中为同一人
- [ ] 引用后各图原有的场景、动作、光线描述**未被人物描述覆盖**

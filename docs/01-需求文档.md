## 这是什么

一个装在 DeepSeek Harness（dsh）里的生图工作台插件。装上之后，dsh 侧边栏多一个「生图」入口，点进去是一个完整的独立页面，不是只能在对话里打字调工具。

自己本地跑，自己用。

## 为什么做

现在生图这件事分成两半，两半都不顺手：

**工程这一半**（Nova Image Studio 那种）：多模型配置、任务队列、历史记录、画廊、反推提示词，功能都有，但提示词写得好不好全靠自己。工具不会帮你想画面。

**创作这一半**（那五个 FANTASY skill）：怎么判断构图、怎么定色彩、怎么让三张图有剪辑关系、怎么让人像不像 AI 娃娃脸，这些判断写得很深。但它们只是几份文档，没有执行体——放在哪个环境跑、能不能真的按 21:9 出图、能不能真的把三张拼起来，全看运气。

把两半合起来：**工作台负责把图稳定地生出来、存下来、管起来；skill 负责在出图之前把画面想清楚。**

## 参照物

UI 形态参照 VisioWork（`@dickpy/dsh-imagegen`）——顶部标签页切换、三栏布局、右侧对话面板可收起。它证明了这种形态在 dsh 里跑得通，长什么样可以直接看它。

但这是重做，不是在它上面加东西。

## 功能全景

十一个功能，没有"第一版不做"这种事——按需推进，但文档里全部写清楚。

**三个核心**（重点做，投入最多）：

| # | 功能 | 一句话 |
|---|---|---|
| 1 | 普通生图（文生图 / 图生图） | 主力页面，日常出图都在这儿 |
| 2 | 视频生成 | **原生内置，不做插件体系**（理由见下） |
| 3 | 无限画布 | 节点连线自由编排，反复迭代 |

**其余八个**：

| # | 功能 | 一句话 |
|---|---|---|
| 4 | 创作 Skill | 五个 FANTASY skill，这是本工作台的差异点 |
| 5 | 画廊 / 素材库 | 作品长期沉淀 |
| 6 | 电商套图 | 一张商品图扩成一整套 |
| 7 | 反推提示词 | 上传图片反推出提示词 |
| 8 | GIF 生成 | 多帧生成 + 拼装 + 编码 |
| 9 | Agent 对话生图 | 在对话里聊着聊着就出图 |
| 10 | UI 设计模式 | 设计稿切图 + AI 复刻网页 |
| 11 | 模板库 / 提示词广场 | 案例参考，一键回填 |

### 关于视频：不做插件套插件

Nova 把视频做成插件包（三个 JSON 文件描述调谁、传什么、怎么轮询），是因为它是**独立 Web 应用**，得自己造一套插件体系才能扩展。

**你这个本身就是 dsh 插件，在插件里再套一层插件没必要。** 视频协议直接内置，和图片模型一样在设置里配渠道就能用。要加新的视频模型，就像加新的图片模型一样——在代码里加一个协议适配，不是让用户去 clone 插件包、放目录、重启。

**【必须】视频和图片在架构上平级。** 不要把视频做成图片的附属品，也不要为视频单独造一套任务、历史、存储。同一套队列、同一个历史记录、同一个画廊。

## 各功能详细要求

### 1. 普通生图（核心）

主力页面。三栏：左边历史记录，中间生图区，右边对话面板（默认收起）。

**中间生图区要有：**

- 文生图 / 图生图两个模式切换
- 提示词输入框
- 比例选择：1:1、3:4、4:3、9:16、16:9、2:3、3:2、21:9，外加「自动」
- 清晰度：自动 / 1K / 2K / 4K
- 一次生成张数：1–4 张
- 细节等级
- 模板库入口
- 提示词增强按钮（一句话扩写成完整提示词）
- **创作 skill 入口**（这是和别的工作台不一样的地方，下面单说）

**图生图额外需要：**

- 上传参考图，也能拖拽、粘贴截图
- 从历史记录、画廊、结果卡一键拿图当参考

**左边历史记录：**

- 每条显示缩略图、提示词、模型、模式
- 按关键词、模型、比例筛选
- 点一条就把当时的参数全填回去
- 能删单条、能清空

**结果区：**

- 多张图并排
- 全屏预览：滚轮缩放、左右翻页、复制提示词、下载
- 一键：加入画廊 / 加入对话 / 作为下次的参考图 / 重新生成
- 生成中显示进度和耗时，能取消，失败能重试

**空状态：** 显示一批灵感案例卡片，点一下把提示词填进去，有个「随机」换一批。
### 2. 视频生成（核心）

和图片平级的一等功能，不是附属品。

**页面要有：**

- 文生视频 / 图生视频两种模式
- 提示词输入
- 首帧图 / 尾帧图上传（图生视频用）
- 参考图、参考视频、参考音频上传（看渠道支持什么）
- 时长选择
- 分辨率 / 清晰度档位
- 比例选择
- 模型选择

**【必须】协议内置，不做插件包。** 支持哪些视频模型就在代码里适配哪些，用户只需要在设置里填地址和密钥。

**视频接口的特点要处理好：**

- 几乎都是异步的：提交拿 task_id，然后轮询
- 等待时间长（几十秒到几分钟），进度要看得见
- 有些返回的是 URL 不是文件，**【必须】URL 原样使用，不要改写域名**
- 有些分档位（标准 / 高清 / 超清），价格差很多，界面上要标清楚

**结果区：**

- 视频能直接播放，带进度条
- 能下载
- 能加入画廊
- 能抽一帧当图片用（去当图生图的参考图、或加进画布）
- 能重新生成
- 显示时长、分辨率、用了哪个模型

**和其他功能打通：**

- 生图的结果一键"拿去做视频"（当首帧）
- 画廊里的图一键"拿去做视频"
- 画布上的图片节点能连到视频生成节点
- 视频也进同一个历史记录、同一个画廊
### 3. 无限画布（核心）

节点式自由编排，适合一个想法反复迭代。

- 三种节点：图片节点、文本节点、生成配置节点
- 拖节点两侧的圆点连线。文本连到配置节点就是提示词，图片连过去就是参考图（第一张当图生图底图）
- 配置节点选中后在底下浮出生成器，写提示词、选模型比例张数，点发送就出图，结果图自动落在右边并保持连线
- 结果可以继续连到下一个配置节点，一路迭代下去
- 画布操作：空格或 Ctrl 拖动平移、滚轮缩放、框选多选、复制粘贴、撤销重做、右键菜单、双击空白建节点
- 左下角小地图，一键「适应全部内容」回正
- 图片节点上能直接：**标注**（框选一块 + 写提示词，只改框里的，框外保持原样，红框不出现在成品里）、**移除背景**、**指定模型**
- 本地图片拖进画布、粘贴截图都能建节点
- 历史和画廊的图一键「加入画布」
- 画布按项目保存，能建多个、能重命名
### 4. 创作 Skill（差异点）

这是这个工作台的核心差异，也是最容易做歪的地方。先说清楚它**不是**什么：

**它不是审查，不是门槛，不是质检员。** 它是一套帮你把画面想清楚的方法。用不用、听不听，你说了算。任何时候你想直接出图，就该能直接出图。

### 五个 skill 分别管什么

| Skill | 管什么 | 出什么 |
|---|---|---|
| **电影三联**（cinema-dna-21x9x3） | 把一个题材想成三个有剪辑关系的镜头 | 3 张 21:9，纵向拼成一张长图；可选再出一张 3:4 项目封面 |
| **生命感人像**（life-force-portrait） | 让人像有生活质感，不是影楼片不是 AI 娃娃脸 | 两种模式：升级已有照片（保住本人）/ 原创人像 |
| **摄影模拟**（photography-simulation） | 在任意地点"拍照"，保持摄影味道 | 摄影感画面 |
| **电影海报**（fantasy-movie-poster） | 从剧情想出一张海报 | 9:16 竖版海报，分层出（底图 + 字体层 + 合成图） |
| **人物选角**（character-casting-studio） | 设计一个能反复用的角色 | 角色形象；显式要求时才出三视图 |

### 在界面里怎么用

**入口在生图区，是一个可选项，不是必经之路。**

选了某个 skill 之后：

1. 你写一句大白话的想法（"明代科举舞弊案"、"给这个角色做张海报"）
2. 点「想方案」，等一会儿
3. 出来一份**创作方案**，摊在你面前：
   - 它是怎么判断的（这场戏的核心矛盾是什么、观众站在哪、视线怎么走、颜色讲什么事、三个镜头之间怎么变化）——**这部分是给你看的，写成人话，不是术语堆砌**
   - 每张图的最终提示词
   - 比例、负面词等参数
4. 你可以直接改这份方案的任何一部分，改完再出图
5. 满意了点「出图」

**方案能存下来、能复用、能改。** 出图失败不用重新想一遍。

### 几条做的时候容易搞错的

- **skill 的参数是真的要生效的。** 电影三联说 21:9 三张，就真的出 21:9 三张；海报说 9:16，就真的 9:16。这不是限制你，这是把活干对——你选了这个 skill 就是想要这个效果。但你手动改比例，得能改得动。
- **负面词自动带上。** skill 里那些"别搞成 CG、别油亮皮肤、别影楼感"的词，出图时自动加进去，不用你每次手打。
- **拼接在本地做，不让模型画。** 三联是三张单独出，然后本地纵向拼起来，中间留点黑边。不能指望模型在一张画布上同时画三格。
- **自检评分只是参考。** skill 里有打分表，让它打完分显示出来，告诉你哪块可能弱。**但绝不拦着你出图。** 分低你想出照样出。想重想就点「重新想一版」。
- **参考图默认只用来分析。** 上传参考图时，默认是让它读一读构图配色，而不是直接拿来当图生图底图——因为这几个 skill 的路子是原创，不是套模板。但你要是就想图生图，切到图生图模式，那就是图生图，别拦着。

### Skill 从哪来

**【必须】读取本地 skill 目录，不要把 skill 内容硬编码进代码。**

- 目录路径可配，默认放在插件数据目录下
- 目录里装了哪几个 skill，界面就显示哪几个；没装的不显示
- 界面上给一句话说明怎么装（clone 到那个目录）
- 注明作者出处（GitHub: dacnay816y62-hub，FANTASY 梵想美学）

这样做的好处：作者更新了 skill，重新拉一下就跟上了，不用改代码。规则的权威副本永远在 skill 目录里，不在你的代码里。

### 几个 skill 之间打架的地方

读原文发现的，实现的时候会撞上：

**海报比例不一样。** 电影三联的封面是 3:4，独立电影海报是 9:16。这俩不是一回事：
- 3:4 那个是"给已经出好的三联做个封面"
- 9:16 那个是"从剧情直接做一张海报作品"

界面上就别让用户猜，做成两个明确的入口。

**海报署名写死了「梵想美学」。** 那是原作者的品牌。做成一个可以改的设置项，默认填他的，你想改就改。

**海报的字是图像模型画的，不是本地排版的。** 原作者明确要求：底图一层、字体设计一层，都由图像模型出，本地只负责裁剪、缩放、挪位置、叠加。不许本地打字。他的理由是大字海报的中文标题要占画面 30%–60%，要有断笔、错位、叠压，本地排版做不出那个味道。

代价是模型可能把中文写错。这个就照实告诉用户："字可能有错，不满意就重出字体层，底图不动"。别自动拦、别自动重试个没完。

**三视图不是默认的。** 选角 skill 默认只出一张人物图，只有你明说"做三视图"才出。这个反直觉，容易做错。

### 5. 画廊 / 素材库

满意的图存这儿，长期积累。

- 从结果卡、全屏预览、历史记录一键加入
- 左边筛选（按模式、模型、比例、自建标签），带数量统计
- 右边瀑布流 / 规整网格两种视图，能按最新最早排序
- 标签能新建、改、删，多选图片批量打标签、批量下载
- 同一张图按内容去重，不会重复入库
- 点图开大图预览，能直接拿去当参考图或加入对话
### 6. 电商套图

一张商品图扩成一整套。

- 上传商品主图（最多 4 张：主体 / 包装 / 细节）+ 可选 1 张风格参考图
- 填商品名称和参数信息，参数可以让 AI 帮写
- 勾选要哪些用途、每种几张：主图、卖点图、场景图、细节图、规格图、使用图
- 先出「套图预览」只看计划，确认了才真的批量生成，不白烧额度
- 先生成主图，其余的都以主图为参考生成，保证是同一个商品
- 每种用途可以单独指定用哪张参考图
- 文案语言可选（中英日韩等），也能自定义
- 结果区主图居左大图，其余用途居右纵排
- 单张能重新生成、下载、加画廊、加对话
- 能导出一份清单，记录每张图的提示词和参数，方便以后复现
- 整组套图在历史记录里折叠成一条，点开能恢复继续编辑
### 7. 反推提示词

上传一张图，反推出能复现它的提示词。

- 上传图片（本地、拖拽、粘贴，或从历史/画廊/结果卡直接拿）
- 选一个视觉模型
- **流式返回**，边推边显示，不要等半天一次性蹦出来
- 结果能复制
- 结果能一键填进生图的提示词框
- 能追加一句指令（比如"只描述构图和光线，不要描述内容"）
### 8. GIF 生成

多帧生成 + 拼装 + 编码成 GIF。

- 输入提示词，描述一个动作或变化过程
- 设帧数
- 生成多帧（保持画面一致性，这是难点）
- 帧序列能预览，能单帧重新生成、能删帧、能调顺序
- 设帧率
- **本地编码成 GIF**，不依赖上游
- 能微调：帧率、循环次数、尺寸
- 导出 GIF
- 帧序列和成品 GIF 都保存
- 能加入画廊
### 9. Agent 对话生图

在对话里聊着聊着就出图，不用切到表单。

- 直接说"画一只猫"就出图
- 出的图内联显示在对话里
- 接着说"把背景改成夜景"，以上一张为参考继续改，**不用重新上传、不用重新描述全部需求**
- 支持斜杠命令快速改图（不经过对话模型，对话模型不支持图片输入时也能用）
- Agent 能看图（视觉描述）
- Agent 能联网搜索（比如"参考一下最近流行的插画风格"）
- 配了多个生图模型时，**【必须】先问用哪个，不要擅自选**
- 没配好渠道时，明确引导去设置，不静默失败
- 对话里的图能加入画廊、能当参考图
- 设置里能关掉"允许 Agent 调用生图"，关了之后工作台页面不受影响
### 10. UI 设计模式

设计稿 → 切图素材 → 复刻成网页。这是十一个功能里最复杂的一个。

**AI 切图：**

- 上传 UI 设计稿
- 视觉模型自动提议切片和背景候选
- **【必须】弹确认框让用户勾选，勾完才真的切**，不要自动存
- 解析失败时自动重试一次

**切图编辑器：**

- 缩放、平移
- 拖拽新建切片框
- 框选多选、8 方向缩放
- 每个角单独设圆角
- 吸附对齐
- 右键菜单
- **【必须】撤销重做至少 50 步**
- 键盘快捷键
- 三种视图：原图（带框线）/ 抠图结果 / 只看切片（棋盘底）

**素材处理**（四种，**【必须】各自独立可撤销，互不覆盖**）：

- 算法抠透明
- AI 抠透明
- 算法转 SVG 矢量
- AI 重绘 SVG

算法类的能批量跑；**【必须】AI 类的一次只跑一个**，防止一次点击烧掉一堆钱。

**背景填充：**

- 调整背景范围框和移除区域框
- 调用带遮罩的图像编辑，把前景挡住的部分补出来
- 同时产出"本地合成版"和"AI 原图版"，让用户选

**网页复刻：**

- 多轮 AI agent，产出三个文件：`index.html` / `styles.css` / `script.js`，外加只读的 `assets/`
- agent 按行编辑文件，不整篇重写
- iframe 实时预览
- 显示上下文用量，接近上限时警告

**导出：**

- 切片包 ZIP（PNG + 可选 SVG + 清单）
- 完整设计包（原图 + 工作区数据 + 网页文件）
- 能从导出包还原工作区

**注意**：带遮罩的图像编辑依赖 OpenAI 协议的 `/images/edits`，其他协议没有对应能力 → 模型选择器里只列支持的模型。
### 11. 模板库 / 提示词广场

## 出图能力要求

### 模型接入

- 能配多个渠道，每个渠道有自己的地址、密钥、模型列表
- 支持 OpenAI 兼容接口，也要能接非标准的（豆包 Seedream、通义 Qwen-Image、MiniMax、Grok Imagine、Gemini 系列这些协议都不太一样）
- 保存地址密钥后能「检测可用模型」，自动过滤掉聊天模型
- 没有 `/models` 接口的网关，能手动填模型名
- 有些接口是异步两步式的（先提交拿 task_id，再轮询），要能自动处理
- 能设一个「提示词增强模型」（聊天模型），给增强功能和电商 AI 帮写用

### 任务处理

- 生图慢，得排队跑，不能卡住界面
- 页面上能看到进度和耗时
- 能取消、失败能重试
- 关了页面再打开，没跑完的任务还在

### 图存哪

- 存本地，默认放用户目录下，能改
- 历史、画廊、画布的图分开存好
- 画廊按内容去重
- 别自动删——本地磁盘不是服务器，图是你的

## 密钥怎么处理

只有这一条是真的需要注意的：

**密钥别明文存在浏览器里，别写进日志。** 由宿主进程持有，前端只知道"配了没配"。上游 API 也由宿主去调，浏览器不直连。

这不是限制你用，是防止你自己的密钥泄露出去。

## 明知道会踩的坑

| 坑 | 打算怎么办 |
|---|---|
| dsh 还在早期，接口可能说改就改 | 锁定一个版本，记下来验证过哪个；升级后按验收清单重跑一遍 |
| 模型把中文字写错 | 照实说，提供"只重出字体层"的按钮，不自动死磕 |
| 三联里三张图的人长得不一样 | 用选角 skill 产出稳定的人物描述，三张都带上同一段；必要时用同一个 seed |
| skill 作者更新了规则，我这边跟不上 | 不复制 skill 文件，只读本地目录；不在自己这边重写一遍它的规则 |
| 一次出 4 张 × 多模型对比，把额度烧光 | 生成前显示预计张数；电商套图先出计划再确认 |
| 页面功能太多，做不完 | 按上面的顺序来，每个阶段都是能用的状态，不做一半的 |
